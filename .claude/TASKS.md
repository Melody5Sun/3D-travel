# 任务清单 · 云游 3D 全景城市漫游

> 最后更新：2026-10-11（第 3 轮：合并第 2 轮分支，完成 P0 验证与 P1 数据）。
> 每次开工先读本文件，从「待办」里优先级最高的一项开始；做完一项就移到「已完成」，并写清楚怎么验证的。

## 原始需求

开发 3D 全景沉浸式旅游网站，默认预置上海：
- 尽量还原现实世界，建模精细到 4K 超清。
- 读者可以选择城市，选后自动进入该城市。
- 默认播放一段电影级运镜的城市宣传片；关键景点出现提示符，读者可以查看介绍或进入景点。
- 支持自由探索，仿佛身临其境。
- 接入第三方 API，获取旅游攻略和附近店铺。
- 以 Loop Engineering 方式开发：完成后自主验证、理解效果，发现问题立即修复。

## 待办

### P1 · 遗留的小问题

- [ ] **没有建模的名胜是带窗格的体块**：凯旋门、圣心大教堂、巴黎圣母院、鸟巢、自由女神像底座、天安门等。可按 `landmarks.js` 的做法逐个补模型，优先凯旋门和鸟巢。
- [ ] **高楼群里的升降镜头**（东京都厅、帝国大厦）开头仍有邻楼屋顶占前景。要彻底解决得给这些景点写手工 `tour`，或在 `autoTour` 里做遮挡检测。
- [ ] **夜景里的公园和低矮景点偏暗**（皇居、李子坝、洪崖洞）。可以考虑给这类景点固定用白天或黄昏。
- [ ] 完整看一遍 9 城的实时播放。本轮内置浏览器面板不在前台，动画帧被限速，除杭州、重庆外都是逐镜头定格检查的。
- [ ] 4K 开关、攻略抽屉、生产构建产物在本轮改动后没有重测。

### P2 · 可选增强

- [ ] T12 宣传片背景音乐：用 Web Audio 生成氛围音，默认静音，可以打开。
- [ ] T13 高德 POI 作为中国城市的店铺数据源：需要 key，并做 WGS84 → GCJ-02 转换。
- [ ] T14 接入 Google Photorealistic 3D Tiles：需要 API key，只覆盖海外城市，不覆盖中国大陆。
- [ ] T15 性能：测 4K 下的帧率；手机上默认降低 `pixelRatio`。
