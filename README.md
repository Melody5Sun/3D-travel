# 云游 · 3D 全景城市漫游

纯前端的 3D 沉浸式城市旅游网站：在真实地理数据构建的 3D 城市里看航拍宣传片，点开景点看介绍、逛附近店铺、进入 360° 实景，再查一份城市攻略。默认城市是上海。

技术栈：Vite 8 + MapLibre GL JS 6 + three.js r186，不依赖前端框架。

## 功能

- **地球开场与选城**：9 座城市（上海、北京、杭州、广州、香港、重庆、东京、纽约、巴黎）。8 秒内不操作会自动进入上海；网址带 `#城市id`（如 `#shanghai`、`#paris`）时直接进入该城市。
- **电影级宣传片**：遮幅、字幕、进度条，从白天过渡到黄昏、夜景。上海是手工编排的无人机运镜，其他城市自动生成环绕航拍。
- **3D 城市**：OpenStreetMap 建筑按高度拉伸，贴上程序生成的窗格立面（高楼为玻璃幕墙，夜里窗户随机亮灯），底图为 Esri 卫星影像；杭州、香港、重庆开启 3D 地形。
- **陆家嘴地标**：东方明珠、上海中心、环球金融中心、金茂大厦由 three.js 程序化建模，替换掉对应位置的 OSM 建筑。
- **景点**：地图标记与提示卡（查看介绍 / 进入景点）。详情面板包含本地精选介绍与游览贴士、维基百科简介与配图，以及 600 米内的餐厅、咖啡馆和商店。
- **进入景点**：镜头飞到近景。外滩和天安门广场可打开 8K（8192×4096）360° 实景全景，其余景点改为缓慢环绕。
- **城市攻略**：来自维基导游（Wikivoyage），按章节折叠显示。
- 键盘飞行（WASD / QE / RF）、白天 / 黄昏 / 夜景切换、4K 渲染开关。

## 快速开始

需要 Node.js 20.19+ 或 22.12+（Vite 8 的要求）。

```bash
npm ci
npm run dev
```

浏览器打开 http://localhost:5173 （端口被占用时以终端输出为准）。

## 构建与静态部署

```bash
npm run build     # 产物输出到 dist/
npm run preview   # 本地预览构建结果：http://localhost:4173
```

- `dist/` 是纯静态文件，没有后端。所有数据接口都由浏览器直接请求，且都不需要 API key。
- `vite.config.js` 设置了 `base: './'`，资源一律使用相对路径，`dist/` 可以部署在任意子路径下，例如 GitHub Pages 的 `https://<用户名>.github.io/<仓库名>/`。
- 必须通过 HTTP(S) 访问。直接双击 `dist/index.html`（`file://`）时，浏览器会以 CORS 为由拦截模块脚本，页面无法启动。
- MapLibre 的 Web Worker 被打包为独立文件 `assets/maplibre-gl-worker-*.js`，从同源加载。maplibre-gl 与 three 各自单独分包，只改应用代码时这两个文件的哈希通常不变，用户可以继续使用浏览器缓存。
- 部署时请保留地图右下角 ⓘ 中的数据署名。

## 使用与操作

| 操作 | 作用 |
|---|---|
| 左键拖拽 / 滚轮 | 平移 / 缩放 |
| 右键拖拽 | 旋转、调整俯仰 |
| 触屏 | 单指平移，双指缩放、旋转、俯仰 |
| `W` `A` `S` `D` | 向前 / 左 / 后 / 右飞行 |
| `Q` / `E` | 向左 / 向右转向 |
| `R` / `F` | 镜头上仰（趋向平视）/ 下俯（趋向俯视） |
| `Esc` | 关闭 360° 全景或侧边面板 |
| 城市名按钮 | 回到地球重新选城 |
| ▶ 宣传片 | 重播当前城市的宣传片 |
| 攻略 | 打开城市攻略 |
| 白天 / 黄昏 / 夜景 | 循环切换时段：天空、光照、影像亮度、道路与窗户灯光、地标照明 |
| 4K | 画布按 3840 像素宽渲染（16:9 窗口即 3840×2160），再点一次恢复。对显卡要求高 |

- 选城页：点击城市卡片立即出发，点击空白处取消自动进入的倒计时。
- 宣传片播放时，点击、拖动或滚动地图，按任一飞行键，或点「跳过宣传片」，都会切换到自由探索。
- 点击景点标记或左侧景点列表打开详情。「附近店铺」可按类别筛选，点击店铺名会飞到它的位置，店铺在地图上显示为黄点。
- 360° 全景：拖动环顾，滚轮或双指缩放，静止 4 秒后自动旋转。
- 调试：浏览器控制台里可以直接使用 `map`、`state`、`CITIES`、`enterCity`、`playTour`、`setMode`。

## 添加城市或景点

所有数据都在 `src/cities.js` 的 `CITIES` 数组里。数组顺序就是选城页的顺序，第一个城市是默认城市（自动进入、带「默认」标记）。

### 坐标必须是 WGS84

底图使用 OpenStreetMap 的 WGS84 坐标。高德、腾讯等国内地图使用 GCJ-02（百度为 BD-09），与底图有数百米偏移，**不要从这些应用复制坐标**。可以在 [openstreetmap.org](https://www.openstreetmap.org) 上定位地点，网址里的 `#map=缩放/纬度/经度` 就是 WGS84 坐标。注意数据里的顺序是 `[经度, 纬度]`。

### 城市

```js
{
  id: 'shanghai',              // 唯一 id，也用作网址 #shanghai
  name: '上海',                // 中文名，同时作为维基导游攻略的条目名
  en: 'Shanghai',
  tagline: '海纳百川 · 追求卓越', // 选城卡片与片头的标语
  color: '#e0457b',            // 选城卡片主题色
  // terrain: true,            // 可选：加载 3D 地形，适合山地城市
  view: { center: [121.4975, 31.2365], zoom: 14.3, pitch: 62, bearing: 40 },
  spots: [ /* 景点，见下 */ ],
  tour: [ /* 可选：手工编排的宣传片，见下 */ ],
}
```

`view.center` 和 `view.bearing` 用于自动生成宣传片的收尾环绕镜头。

### 景点

```js
{
  id: 'bund',                  // 城市内唯一
  name: '外滩', en: 'The Bund',
  ll: [121.48665, 31.2388],    // [经度, 纬度]，WGS84
  h: 60,                       // 主体高度（米），决定镜头的距离和高度
  wiki: '外滩',                 // 中文维基百科条目名，用于简介和配图
  desc: '……',                  // 本地精选介绍，维基百科不可用时照常显示
  tips: ['……', '……'],          // 游览贴士
  pano: {                      // 可选：360° 全景
    url: 'https://…/shanghai_bund.jpg', // 2:1 等距柱状投影图片，服务器需允许跨域（CORS）
    yaw: 0.587,                // 0–1：打开时正对图片哪个水平位置
    credit: 'Greg Zaal / Poly Haven · CC0',
  },
}
```

### 宣传片镜头（可选）

没有 `tour` 时会自动生成：每个景点一段 8 秒的环绕镜头（半径和高度由 `h` 推算），时段依次从白天到黄昏再到夜景，最后是 12 秒的全城夜景环绕。

需要手工编排时，`tour` 是一组镜头，每个镜头二选一使用以下两种运镜：

```js
tour: [
  // 直线运镜：相机 cam 与注视点 look 各自从第一个点移动到第二个点，点格式 [经度, 纬度, 海拔(米)]
  { title: '外滩', sub: 'THE BUND · 万国建筑博览群', spot: 'bund', dur: 11, mode: 'day',
    cam: [[121.4893, 31.2318, 270], [121.4880, 31.2445, 310]],
    look: [[121.5000, 31.2368, 150], [121.4995, 31.2402, 170]] },
  // 环绕运镜：orbit: [经度, 纬度, 目标高度, 半径, 相机高度, 起始方位角, 结束方位角]
  { title: '东方明珠', sub: 'ORIENTAL PEARL TOWER · 468 m', spot: 'pearl', dur: 10, mode: 'day',
    orbit: [121.49527, 31.2419, 220, 560, 300, 245, 325] },
]
```

- `title` / `sub`：字幕标题与副标题；`spot`：可选，镜头期间高亮的景点 id；`dur`：时长（秒）；`mode`：`'day'`、`'dusk'` 或 `'night'`。
- `orbit` 的方位角是从目标指向相机的方向（度，0 为正北，顺时针）；半径和高度的单位都是米。
- 开启地形的城市可以给 `orbit` 镜头加 `ground: true`，高度改为相对目标处的地面。

注意：three.js 地标模型只有陆家嘴四座，写死在 `src/landmarks.js`，新增城市只会显示 OSM 建筑。

## 网络说明

- 维基百科、维基导游和 Overpass 需要能正常访问国际互联网，在中国大陆通常需要代理。访问失败时，应用仍会显示本地精选介绍和贴士；附近店铺改用矢量瓦片里的 POI；攻略面板提示稍后重试。
- 其余数据源（OpenFreeMap、Esri、AWS、Poly Haven）都在境外，加载速度取决于网络。每张全景图约 4–5 MB。

## 已知限制

- 没有实景三维（倾斜摄影）模型：Google Photorealistic 3D Tiles 需要 API key，而且不覆盖中国大陆。城市建筑都是 OSM 轮廓按高度拉伸，只有陆家嘴四座地标是手工建模。
- OSM 建筑高度数据的完整度因城市而异，缺少高度信息的建筑会显得偏矮。
- Overpass 公共服务器可能繁忙或限流，此时店铺列表回退为矢量瓦片 POI，没有营业时间、菜系和官网等信息。
- 只有上海有手工编排的宣传片，只有外滩和天安门广场有 360° 全景。
